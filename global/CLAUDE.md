- 답과 산출물은 한국어로 쓴다. 전문 용어는 처음 나올 때 한국어 개념어로 풀고, 원어는 괄호에 둔다.

## relay (파일 기반 인수인계)
- 프로젝트에 `.relay/`가 있으면 세션을 `/pickup`으로 시작하고, 작업 단위가 끝나거나 컨텍스트가 커지면 `/handoff` → `/clear`를 제안한다.
- 상태 파일·작업 카드·relay CLI·훅의 형식, 예시, 스크립트는 relay 스킬(`~/.claude/skills/relay/`)에 있다. 필요할 때만 읽는다.
- 카드의 `done_when` 종료 코드 0만 완료다. 모델 판단으로 done을 쓰지 않는다.
